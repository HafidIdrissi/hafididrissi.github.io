## 👋 About

Software engineer from the Paris region, graduated from **JUNIA** (French *diplôme d'ingénieur*, master's grade, 2024).
I design and build digital products end to end — from requirements and architecture through implementation, testing and deployment.

Two R&D internships shaped how I work: **Hager Group**, where I built a proof of concept for deploying IoT APIs securely on Azure Kubernetes Service inside a private network, and **Mirion Technologies**, where I built a real-time 2D LiDAR/SLAM mapping prototype on embedded Linux.
Since then I have been building my own products — SaaS platforms, browser-side tools and applied ML prototypes — mostly alone, from database schema to CI/CD.

> **Boring infrastructure. Exciting products.**

### 🔋 Bayesian battery SOH

**Hierarchical inference for Li-ion health**
<sub>Research groundwork · Apr 2026</sub>

- Two Bayesian approaches compared: per-battery model vs. **hierarchical model** pooling fleet-level information
- Exponential degradation dynamics; posteriors over initial state, degradation rate and observation noise
- **NUTS** inference with PyMC and NumPyro, posterior predictive checks, remaining-life estimates with 90% credible intervals
- Inter-battery variability across 8 simulated units and 150 cycles

`Python` · `PyMC` · `NumPyro/JAX` · `ArviZ`

<sub>⚠️ Simulated dataset inspired by NASA PCoE — not validated on real cells.</sub>

[![Repo](https://img.shields.io/badge/Repo-181717?style=flat-square&logo=github&logoColor=white)](https://github.com/HafidIdrissi/bayesian-soh-batteries)

### ☁️ Hager Group — Final-year internship
**Cloud & IoT architecture (AKS proof of concept)**
<sub>Obernai (67), France · Apr → Oct 2024</sub>

Architecture & Integration Management team, IoT Cloud Factory.
Brief: assess whether Hager's IoT APIs could be deployed securely on **Azure Kubernetes Service** over a private network.

- Owned the PoC end to end, from reviewing the existing setup to validation testing
- Designed a **private Azure architecture across three VNets**, with VNet Peering and Private Endpoints securing traffic between AKS, VMs and Azure SQL
- Containerised and orchestrated .NET IoT APIs with Docker, Docker Compose and Kubernetes; added health checks and fixed Azure SQL connectivity
- Solved an **ARM64 image incompatibility** with a compatible builder, then an AMD64 node pool and cluster autoscaling
- Produced a monthly cost estimate for the target architecture, stating assumptions and what remained to refine
- Built an IoT energy-prediction prototype with a cross-functional team, presented to a Hager–Microsoft jury at the GenIA hackathon

`Azure` `AKS` `Kubernetes` `Docker` `Azure SQL` `VNet` `Azure DevOps` `.NET` `Databricks` `Azure OpenAI`

### 🛰️ Mirion Technologies — R&D internship
**Embedded systems, SLAM & operator HMI**
<sub>France · Jun → Aug 2023</sub>

R&D department.
Brief: design a mobile mapping interface for an industrial inspection system, combining LiDAR, SLAM and real-time visualisation on an embedded platform.

- Designed and validated a **real-time 2D mapping prototype** end to end, from requirements to SLAM selection and functional testing
- Built the **ROS Noetic / Python** architecture around an RPLIDAR A1M8, an HWT905 orientation sensor and Hector SLAM, with real-time data flow over ROS topics and RViz visualisation
